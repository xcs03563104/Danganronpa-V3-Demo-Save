### 介绍

此为Danganronpa V3: Killing Harmony Demo Ver.纯手打通关存档数据

在新枪弹辩驳V3 大家自相残杀的新学期中点击开启新游戏并加载体验版通关数据即可得到通关特典（333黑白熊金币、机关枪技能、指甲刷礼物）

在正式版中，第一章期间黑白熊扭蛋机尚未解锁，玩家在正常的一周目流程中无法常规获得礼物道具指甲刷

通过导入本体验版通关存档，正式版开局即可直接获得以下特典：

1.礼物道具【指甲刷（Nail Brush）】

持有该道具后，可在第一章在与最原终一探索完图书馆后的第二天早上与白银纺对话，从而在第一周目直接触发她的特殊隐藏剧情（无需等到通关后用章节选择补看）

2.黑白熊金币*333

3.学级裁判技能【机关枪（Machine Gun）】


### 具体使用方法如下

请确保你有steam正版游戏（即新枪弹辩驳V3 大家自相残杀的新学期）

下载仓库文件压缩包并解压

将解压出的 567640 文件夹，放入以下目录：

你的Steam安装目录\userdata\你的Steam数字ID\

放好存档后启动正式版，在主界面点击开始新游戏（New Game），系统会询问是否继承体验版通关数据，选择确认即可

如果已经开始了正式版剧情并保存了进度，无法直接在现有存档中追加领取，必须重新开启新游戏
